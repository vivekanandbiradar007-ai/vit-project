📘 Course Overview

CSS (Cascading Style Sheets) is used to style HTML webpages. It controls colours, fonts, spacing, layouts, animations and responsive designs.

This course helps students build attractive, user-friendly and mobile-responsive websites through practical exercises and projects.

Course

CSS Fundamentals to Advanced CSS

Learning Mode

Theory, coding practice and projects

Prerequisite

Basic knowledge of HTML recommended

🎯 Course Objectives

  • Understand CSS syntax and styling methods.
  • Apply colours, fonts, borders, spacing and backgrounds.
  • Design layouts using Flexbox and CSS Grid.
  • Create responsive webpages for mobile and desktop devices.
  • Implement transitions, animations and visual effects.
  • Develop complete website interfaces through practical projects.

📚 Detailed Course Syllabus

Module 1: Introduction to CSS

What is CSS, advantages of CSS, CSS syntax, selectors, declarations and CSS comments.

Module 2: Applying CSS

Inline CSS, internal CSS, external CSS, linking stylesheets, cascading rules and inheritance.

Module 3: Selectors

Element, class, ID, universal, grouping, attribute, descendant, child and pseudo-class selectors.

Module 4: Colours and Typography

Colour names, HEX, RGB, RGBA, HSL, font families, font sizes, text alignment and text decoration.

Module 5: CSS Box Model

Content, padding, border, margin, width, height, box-sizing and element spacing.

Module 6: Display and Positioning

Block, inline, inline-block, none, static, relative, absolute, fixed, sticky and z-index.

Module 7: Flexbox

Flex containers, flex items, direction, alignment, justify-content, gap, wrapping and responsive layouts.

Module 8: CSS Grid

Grid containers, rows, columns, gaps, grid templates, item placement and two-dimensional layouts.

Module 9: Backgrounds and Borders

Background colours, images, gradients, border styles, border radius, shadows and opacity.

Module 10: Responsive Web Design

Media queries, breakpoints, flexible layouts, responsive units and mobile-first design.

Module 11: Transitions and Animations

CSS transitions, transforms, keyframes, animations, hover effects and interactive elements.

Module 12: Advanced CSS

CSS variables, pseudo-elements, attribute selectors, specificity, reusable styles and maintainable CSS.

💻 Practical Example

Use the following CSS to style an HTML heading and paragraph.

body {
    font-family: Arial, sans-serif;
    background-color: #f4f6f9;
}

h1 {
    color: #11998e;
    text-align: center;
}

p {
    color: #333;
    font-size: 18px;
    line-height: 1.6;
}

Hands-on Practice
